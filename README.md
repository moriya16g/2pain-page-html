# 2-Pane Viewer

左ペインにテキスト、右ペインにテキスト位置に連動した画像を表示する HTML テンプレートです。  
サーバー不要で、`index.html` をブラウザで直接開くだけで動作します。

## ファイル構成

```
├── index.html      … メインページ（HTML / CSS / JS）
├── content.js      … 表示するテキストと画像の対応定義
├── images/         … 画像ファイルの配置フォルダ
│   ├── sample1.png
│   ├── sample2.png
│   └── ...
└── README.md
```

## 使い方

### 1. 画像を配置する

`images/` フォルダに表示したい画像ファイルを入れます。  
サブフォルダも使えます（例: `images/chapter1/fig1.png`）。

### 2. content.js を編集する

`content.js` にテキストと画像の対応を記述します。  
ファイル全体は以下の形式です。

```js
const CONTENT = `
ここにテキストを書く
`;
```

バッククォート（`` ` ``）の中にテキストを記述します。  
テキスト中にバッククォートを使う場合は `\`` とエスケープしてください。

### 3. ブラウザで開く

`index.html` をダブルクリック、またはブラウザにドラッグ＆ドロップして開きます。

## content.js の書き方

### 画像タグ

テキスト中に以下の形式で画像タグを挿入します。

```
[@image: 画像ファイルのパス]
```

このタグから次のタグまでのテキストが、指定した画像に対応します。  
左ペインをスクロールして該当テキストが表示領域に入ると、右ペインの画像が自動的に切り替わります。

### 見出し

行頭に `#` を書くと見出し（h1）として表示されます。

```
# これは見出しです
```

### 段落

空行で区切られたテキストが1つの段落になります。

## 画像操作

右ペインに表示された画像は以下の操作が可能です。

| 操作 | 動作 |
|------|------|
| マウスホイール | 拡大・縮小（カーソル位置を中心） |
| ドラッグ | 表示位置の移動 |
| ダブルクリック | 表示をリセット（フィットに戻す） |

画像はペインに収まるよう自動的に拡大・縮小されて表示されます。

## ペイン幅の調整

左右ペインの間にあるグレーの境界線をドラッグすると、ペインの幅比率を変更できます。

## ライト / ダークモード

左ペイン右上の ☀ ボタンをクリックすると、テキストペインのライトモード / ダークモードを切り替えられます。  
ボタンは普段は薄く表示され、マウスを重ねると明瞭になります。
